# 스마트폰 사용 점검

실제 개인 기록과 별도로, 새 브라우저 프로필이나 테스트 기기에서 샘플로 확인하세요. 개인 기록이 있는 브라우저의 저장 데이터를 테스트를 위해 지우지 않습니다.

## 화면과 입력

1. Mac 개발자 도구의 반응형 화면에서 375 / 390 / 414 / 430px 너비를 확인합니다. 홈과 모든 탭에서 가로 스크롤이 없어야 합니다.
2. 새 기기 시작 화면에서 ‘새로 시작하기’를 누릅니다. 홈 하단 탭과 복습 CTA를 확인합니다.
3. ‘새 레슨 기록’에서 클럽/아카데미를 선택하고 긴 원문을 입력합니다. 키보드가 열린 상태에서도 작성창을 스크롤하고 저장 버튼까지 이동할 수 있어야 합니다. 입력 글자 크기는 16px 이상입니다.
4. 창을 닫아 홈에서 ‘이어쓰기’를 누르면 원문·날짜·회차·분석 항목을 다시 확인할 수 있어야 합니다.
5. 작성 도중 앱을 닫았다 다시 열어도 초안이 나타나야 합니다. 저장한 뒤에는 초안 배너가 사라져야 합니다.
6. 기록 탭의 ‘대회 기록’에도 같은 초안/저장 흐름을 확인합니다.
7. 레슨/대회 상세에서 긴 문장과 원문 토글의 줄바꿈, 글자 크기, 터치 영역을 확인합니다.

## 저장과 복습

1. 클럽·아카데미·대회가 섞인 TXT를 가져와 원문·날짜·분류를 확인합니다.
2. 페이지 새로고침, 앱 종료 후 재실행에도 저장 기록과 수동 입력 날짜가 유지되어야 합니다.
3. 오늘의 복습을 완료하고 새로고침합니다. 완료 횟수와 카드의 다음 복습 날짜가 유지되어야 합니다.
4. 문제는 하나씩, 선택지는 세로로 표시되고 다음 문제 버튼을 누르기 쉬워야 합니다.

## 백업과 복원

1. 설정 → 전체 데이터 백업으로 JSON을 내려받아 파일 앱에 보관합니다.
2. 새 테스트 프로필에서 백업을 선택합니다. 미리보기의 레슨·대회·피드백·복습·초안 개수를 확인합니다.
3. ‘취소’를 누르면 현재 데이터가 바뀌지 않아야 합니다.
4. 파일을 다시 선택해 ‘복원하기’를 누릅니다. 모든 기록과 초안, 복습 결과가 복원되어야 합니다.
5. 잘못된 JSON이나 다른 앱의 파일을 선택하면 오류가 표시되고 현재 데이터가 유지되어야 합니다.
6. 실제 기기를 바꾸기 전에는 이 흐름을 한 번 확인해 주세요.

## 배포와 홈 화면

1. GitHub Pages의 `/저장소명/` 주소에서 CSS·JS·아이콘·manifest가 모두 로드되는지 확인합니다.
2. iPhone Safari의 공유 메뉴 또는 Android 브라우저 메뉴에서 홈 화면에 추가합니다.
3. 홈 화면 아이콘으로 실행하면 앱 이름과 standalone 화면이 나타나야 합니다.
4. 코드 재배포 후 같은 주소·같은 브라우저로 다시 열어도 기록이 유지되어야 합니다.
5. 주소나 브라우저가 달라지면 저장소가 달라지므로 백업 파일로 옮깁니다. 완전한 오프라인 실행은 현재 지원 범위에 포함되지 않습니다.
